# String Setter support

String Setter is a single screen, shaped like a guitar, for tuning one.

**Tuning** at the top picks the tuning: standard, half and full step down, drop D and C,
open E, D and G, and DADGAD. The pegs relabel to match.

**Pegs** choose the string to tune. Pluck it and read the sound hole: the needle shows
where the string is, flat to the left and sharp to the right, and the label across from
it says which way to turn: **Tighter** when the string is low, **Looser** when it is high.
The scale spreads out near the mark, so the needle moves fast while the string is far off
and slows down as it gets close. Within 4 cents the note turns green and the phone gives
one tap.

A string an octave away, or more than a fifth off, is called out as the note heard ("Hearing
D3"), so a string in the wrong octave never shows as in tune.

**Chromatic** on the bridge names any note you play, octave included, with the needle
reading flat and sharp.

Phone microphones hear little of the lowest strings, so let other strings stop ringing
before you tune, especially one an octave away from the string you are on.

The screen stays on while the app is open.
